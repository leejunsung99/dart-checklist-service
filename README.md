# 공시 바로알기 · 내 업무 체크가이드

상장사 공시 담당자가 6개 질문에 답하면 **준비할 자료, 검토 부서, 외부 확인 경로, 점검 체크리스트**를 한 장으로 정리해 주는 정적 웹 서비스입니다. 마지막 화면에서 루미네어IR IR/PR 컨설팅 문의로 이어집니다.

## 구조

```
index.html        페이지 뼈대 (헤더·푸터)
css/style.css     스타일 (기본 → 루미네어 브랜드 → 반응형 → 인쇄)
js/data.js        업무 유형·단계·세부 상황·링크·연락처 데이터
js/app.js         화면 흐름: 홈 → 질문 6개 → 결과 카드
assets/logo.png   루미네어IR 로고
```

콘텐츠(문구, 체크리스트 항목, 연락처)는 `js/data.js`에서 수정합니다.

## 로컬 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열거나 다음 명령을 실행합니다.

```bash
npx serve .
```

## 배포

정적 파일만 있으므로 Netlify, GitHub Pages 등에 저장소 루트를 그대로 배포하면 됩니다.

## 참고

이 가이드는 규칙 기반 업무 준비 안내이며 공시 대상 여부나 제출기한을 확정하지 않습니다. 선택값은 서버로 전송되지 않습니다.
