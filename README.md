# 공시 바로알기 · 내 업무 체크가이드

상장사 공시 담당자가 시장·자산 규모·사건·단계·규모 비율·외부 노출 상황을 고르면 **공시의무 판정, 제출 시한, 해설서 근거 페이지, 체크포인트, 자주 틀리는 부분, 후속 공시, 공정·조회공시 리스크**를 한 장으로 정리해 주는 정적 웹 서비스입니다. 마지막 화면에서 루미네어IR IR/PR 컨설팅 문의로 이어집니다.

## 구조

```
index.html        페이지 뼈대 (헤더·푸터)
css/style.css     스타일 (기본 → 루미네어 브랜드 → 반응형 → 인쇄)
js/data.js        업무 유형·단계·외부 노출 시나리오·비율 기준표(METRICS)·링크·연락처
js/items.js       공시 항목 55개 (시장별 기준·시한·페이지, 체크포인트, 실수, 후속 공시)
js/app.js         화면 흐름: 홈 → 질문 5~7개(답에 따라 분기) → 판정 + 결과 카드
assets/logo.png   루미네어IR 로고
```

공시 항목 내용은 `js/items.js`, 비율 기준·질문 보조 문구·연락처는 `js/data.js`에서 수정합니다.

## 콘텐츠 근거

한국거래소 「코스닥시장 공시·상장관리 해설」('25), 「유가증권시장 공시·상장 업무해설서」, 「2026 코스닥 상장심사 이해와 실무」, 「중복상장 가이드라인」('26.8.3)에서 항목별로 추출했습니다. 항목별 해설서 페이지는 `js/items.js`의 `page` 필드에 남겨 두었습니다(화면에는 표시하지 않음). 규정 개정 시 해당 항목을 갱신해야 합니다.

## 로컬 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열거나 다음 명령을 실행합니다.

```bash
npx serve .
```

## 배포

정적 파일만 있으므로 Netlify, GitHub Pages 등에 저장소 루트를 그대로 배포하면 됩니다.

- **운영 주소**: https://luminaireir-checklist-service.netlify.app/
- Netlify가 GitHub 저장소(`leejunsung99/dart-checklist-service`)의 `main` 브랜치에 연결되어 있어, `main`에 푸시하면 자동으로 다시 배포됩니다.

## 참고

이 가이드는 해설서를 요약한 업무 안내이며, 개별 건의 최종 판단은 현행 규정과 거래소 확인을 따릅니다. 선택값은 서버로 전송되지 않습니다.
